소소한 팁/정보

간단하고 유용한 윈도우 단축키 모음

혹시 마우스로 일일이 클릭해서 창을 옮기거나, 파일 탐색기를 열 때마다 시작 메뉴부터 뒤지고 계신가요? 단축키 몇 개만 외워두면 이런 작업들이 훨씬 빨라집니다. Ctrl+C·Ctrl+V처럼 이미 다 아실 만한 건 빼고, 정말 자주 쓰는 것들만 추려봤어요.

① 창 정리·화면 관리

단축키기능
Win + ← / →창을 화면 절반에 붙이기(스냅)
Win + ↑창 최대화
Win + ↓창 최소화 · 이전 크기로
Win + D모든 창 한번에 최소화(바탕화면 보기)
Alt + Tab실행 중인 창 전환

② 캡처·기록

단축키기능
Win + Shift + S화면 일부만 캡처(스니핑 도구)
Win + G게임 녹화·캡처 바 열기

③ 복사·붙여넣기

광고 영역 (in-article)
단축키기능
Win + V최근 복사한 내용 25개까지 다시 붙여넣기(클립보드 히스토리)
Ctrl + Shift + V서식 없이 텍스트만 붙여넣기

④ 자주 쓰는 화면 빠르게 열기

단축키기능
Win + E파일 탐색기 열기
Win + I설정 열기
Win + L화면 잠그기(자리 비울 때)
Win + X전원 · 장치 관리자 등 관리자 메뉴

⑤ 브라우저 공통(크롬 등)

단축키기능
Ctrl + Shift + T방금 닫은 탭 다시 열기
Ctrl + T새 탭 열기
Ctrl + W현재 탭 닫기
Ctrl + L주소창으로 커서 이동

⑥ 텍스트 편집

단축키기능
Ctrl + Z / Ctrl + Y실행 취소 · 다시 실행
Ctrl + Backspace단어 단위로 한번에 지우기

참고로 창 제목 표시줄을 마우스로 잡고 좌우로 살짝 흔들면, 지금 보고 있는 창만 남기고 나머지 창이 전부 최소화됩니다. 다시 흔들면 원래대로 돌아와요 — 몰랐던 분들이 은근히 많은 기능입니다.
